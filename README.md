# E-Commerce Sales Analysis

## Descripción
Análisis de datos de ventas de e-commerce con Python.

## Datos
- 100,000 transacciones
- 5 categorías de productos
- 2 géneros de clientes

## Análisis realizado
1. Ventas totales por categoría
2. Ventas por género
3. Precio promedio por categoría

## Conclusiones
- Clothing es la categoría con más ventas (~$61M)
- Las ventas están equilibradas entre géneros (50/50)
- Clothing y Books tienen precios más altos que otros productos

## Cómo ejecutar
```bash
python analisis_datos.py
```
